# 初期テンプレートの初回フィットを調べる

`app/peak_timing` から独立したチェック用プログラムです。条件変更を決める前に、
初回フィットのχ²分布と実際の波形への適合を確認します。通常アプリの `all` ターゲットには含めません。

```bash
conda activate root_env
make -j2 check-template-fit
./build/check_initial_fit data/scan_20261021_164141.root
```

保存先は `results/<Run>/template_fit_check/initial_chi2_v1/`。
既存結果には上書きしません。再実行は `--output-dir` で新しい保存先を指定してください。

```bash
./build/check_initial_fit data/scan_20261021_164141.root \
  --channels 1 --template-amplitude-mv 150:200 \
  --chi2-edges 0,1,2,3,5,10,20,50,100,inf --examples-per-bin 3 \
  --output-dir results/scan_20261021_164141/template_fit_check/amplitude150_200
```

## どの段階を調べるか

1. ラン全体の偶数ショットから、現行 `peak_timing` と同じ品質・振幅条件で候補を選択。
2. 同じ位置別reservoirとラウンドロビン、同じ乱数seedで上限まで抽出。
3. 線形CFD50整列・pol2振幅規格化・ディザ・平滑化で**初期テンプレートだけ**を作成。
4. この初期テンプレートで選択候補を全数フィット。
5. χ²/ndfが3を超えていても、数値が求まったフィットを分布と代表例に残す。

これは通常ビルダーの **stage=1の選別判定時に使うフィット** に相当します。
更新1後・更新2後のテンプレートや、奇数ショットの分解能評価ではありません。
完成テンプレートの残差を見て初期選別を説明しないよう、段階を固定しています。
作成時に使用した波形への適合度なので、独立評価の精度や分解能を示しません。

計算の複製を避けるため、共通ライブラリに `BuildInitialPulseTemplate` を追加しています。
通常の `BuildPulseTemplate` と同じ内部処理を通り、初期作成直後に戻ります。
通常ビルダーの更新回数、品質条件、χ²閾値、最低件数は変えていません。
その後の判定で100本未満になる場合も、チェックでは初回結果をそのまま保存します。
最初から作成候補が最低件数に達しないchは `channel_status.csv` に理由を記録し、他chを続行します。

## 出力

- `conditions.json`: 入力ROOT内容MD5、共通ソースSHA256、チェックソースMD5、引数・区間・条件。
- `candidate_selection.csv`: ラン全位置の品質選別理由別件数と位置別reservoir採用数。
  `ok` は品質条件通過数、`reservoir_retained` はその内数で、足し合わせる値ではありません。
- `channel_status.csv`: ch別の選択数・有限χ²数・元の品質判定の通過数・数値なし件数。
- `diagnostics.root`: ch別のχ²/ndfヒストグラム（全域線形・全域対数・0–20拡大）、生χ²、累積分布。
- `C*/initial.template`, `initial_template.csv`: **初期のみ**のテンプレートとstage=0の候補ID。
  診断用です。反復済みテンプレートとして本解析へ渡さないでください。
- `C*/first_fits.csv`: 選択候補全数のフィット時刻・振幅・ノイズ・SSE・ndf・生χ²・χ²/ndf・採否・理由。
- `C*/chi2_distributions.png`: χ²/ndf全域（対数軸）、0–20拡大、生χ²全域、累積分布。
  赤破線は元の判定閾値3。高χ²を切り捨てません。対数図の0は注記し、全域線形ヒストグラム・CSVには含めます。
- `C*/chi2_correlations.png`: 測定点ID、pol2振幅、ノイズRMSに対するχ²/ndf。
  IDは位置そのものではなく、実座標は `candidate_selection.csv` に保存しています。
- `C*/chi2_bins.csv`: χ²/ndf区間別の件数、元の判定通過件数、割合、最小・中央値・最大。
- `C*/examples.csv`: 区間・χ²順順位・event/segment ID・χ²/ndf・重ね図への相対パス。
- `C*/examples/*.png`: フィット窓のサンプル＋初期テンプレートフィット、ピーク付近の拡大、
  ノイズRMSで割った残差の3パネル。χ²>3のフィットも赤線で描画します。
- `C*/example_samples.csv`: 代表例の実サンプル、モデル電圧、窓内判定、標準化残差、χ²への各点の寄与。
- `C*/fit_reasons.csv`, `position_summary.csv`: 失敗理由別件数、位置別の有限件数・通過数・χ²・残差・ノイズ。

区間は既定 `[0,1), [1,2), [2,3), [3,5), [5,10), [10,20), [20,50), [50,100), [100,∞)`。
各区間のχ²順で最小・中央・最大の最大3波形を表示します。同数値の場合はevent/segment順です。
全候補から代表例を選び、採否や見栄えで選び直しません。`--examples-per-bin 1` は中央の1例です。
境界は下端以上・上端未満。元の通過判定はχ²/ndf≤3なので、ちょうど3は `[3,5)` に入って通過扱いになります。
数値が得られないフィットはχ²分布に混ぜず、`first_fits.csv` と理由別件数に残します。

生χ² = SSE / baseline_noise_V²、ndf = 窓内実サンプル数 − 3。
サンプル間ノイズ相関・テンプレート推定誤差は考慮していません。
χ²が大きい理由を、形状の差とノイズに対する残差の両面から確認してください。

## 検証

```bash
make test
python3 checks/template_fit/test_check.py
```

数値テストで、チェック用初期テンプレートのフィットと通常ビルダーstage=1のχ²・採否・理由が一致することを検査。
独立した人工ROOT入力では、χ²>3の保存、区間と代表例の選択、各サンプルのモデル補間、
χ²の寄与・総和、ROOTヒストグラムのエントリー数、既存結果の上書き拒否を検証します。
すべての検証用ファイルはプロジェクトの `build/` 内へ保存します。
