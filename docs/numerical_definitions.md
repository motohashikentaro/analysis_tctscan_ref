# 引き継いだ数値定義

## 入力と単位

元ROOTの `waveforms` / `scan_info` と既存ブランチ名・型を維持しています。1entryは1測定点・1ショットのC1〜C4です。`event_number` はCSV index・TRC末尾番号と対応します。

電圧は `raw * gain_V_per_count - vertical_offset_V`、時刻は `t0_s[ch] + sample * dt_s[ch]` です。元ROOTのfloat電圧をdoubleへ展開して計算します。表示は時間ns・電圧mV、座標はµmです。TRCの再変換時もfloatへの丸め方を維持します。

## 平均波形

同じ測定点・同じチャンネルで選択したショットを平均します。既定のtrigger平均は全ショットに共通する時間範囲を求め、元のdtの格子へ線形補間します。外挿やピーク位置合わせは行いません。加算は補償加算です。

sample-index平均は同じサンプル番号の電圧を平均し、時刻を `mean(t0) + sample * dt` とします。clippedショットも含め、件数を保存します。

## 波高とスキャン

ベースラインは指定窓内の算術平均、ピークは信号窓内の最小電圧です。波高は `baseline - minimum`。平均波形の波高と、各ショットの波高の平均は異なる量です。

1Dは元データの出所 `_1dX` / `_1dY` / `_1dZ` と座標整合を確認し、主軸の昇順に並べます。XYは `_2dXY` / `_2dYX` と完全な直交格子を確認し、Xを横・Yを縦に配置します。位置の許容幅は1e-6µmです。1dX/YおよびXYのZ追従を認めます。

XYの順位は、平均波形の最小電圧が低い順です。ベースライン差し引き後の波高順とは区別します。同値は小さいチャンネル番号を優先します。合計波高は各チャンネル独立の波高の和です。

## 個別ショットの時刻（テンプレート版、2026-11-24）

旧ガウシアン解析を削除し、元の負極性波形に `b-A*T(t-tau)` をフィットします。
テンプレートTはピーク1・立ち上がり50%交点0。ToA=`tau`、ピーク時刻=`tau+Tのピーク位置`。
最小サンプル時刻も独立に保存し、その最小値が同値の場合はフィット比較から除きます。
線形CFD50は既存の `AnalyzeCfd` を再利用し、サンプル波高の50%・ピーク前の最後の交点を隣接2点で線形補間します。
時間軸はショットごとのTRIGTIME由来の元の時間軸です。位置の到達遅延を引きません。

作成対象はラン全体の偶数segment、評価は指定した測定点・segment範囲の奇数segmentです。
作成候補は非飽和、信号窓端でないピーク、S/N≥20、pol2波高200–350 mV、CFD交点・必要記録範囲がある波形。
pol2は最小サンプルと前後1点の3点で、正曲率・唯一の最小サンプル・頂点が中心の±0.5サンプル以内を要求します。
S/Nはサンプル波高／ベースライン標本標準偏差（N−1）。最低100本、各位置最大100本、全体最大2000本/ch。
位置別一様reservoir抽出とシャッフルラウンドロビン（固定seed、既定1729）で位置偏りを抑えます。
leadingかどうかを要求せず、強い信号と品質で選びます。端ストリップ用のビーム条件は適用しません。

線形CFD50で初期整列、pol2波高で規格化。整列時刻に±50 ps一様ディザを加え、A²重みで1 psビンに積みます。
ビンの重み付き電圧和と重み和に、それぞれsigma=20 ps・±4sigmaのガウスカーネルを掛け、比を取って5 ps格子へ出力します。
空ビンを0の波形として補いません。支持範囲は初期座標で−2.5〜+3.0 ns。
候補はディザと平滑化の余裕も含む記録範囲を要求します。完成ごとにピークを1、線形補間のCFD50を0へ再規格化します。
ピークはこの区分線形テンプレートの最大格子点です。5 ps格子に伴うピーク位置の離散性は残ります。

初期作成後、テンプレートフィットで得たtau・A・bで整列・規格化し直す更新を2回行います。
各回chi2/ndf>3・フィット不正の候補を除外し、一度除いた候補は復帰させません。
最後に完成テンプレートで検査し、最低件数を確認します（この最終検査では再構築しません）。
`template_uses.csv` のstage=0は初期、1/2は更新に用いる選別、3は最終検査です。
完成形状に寄与したショットの集合はstage=2のacceptedです。独立評価に使えるのは未使用の奇数ショットです。

フィット窓は初期線形CFD50の−1.5〜+2.0 ns。実サンプルのうち窓に入るものを使うため、
10 GS/sでも交点とサンプルの位相により点数は35または36です。記録外に出る場合はフィットしません。
初期時刻の±300 psを5 ps刻みで走査し、各時刻でA,bの等重み最小二乗解を閉形式で計算します。
A>0を要求、時刻探索端は失敗。最小SSE近傍3点の放物線補間後、A,bを再計算しSSEが改善した場合に採用します。
テンプレート格子間は線形補間し外挿しません。ndf=Nfit−3、chi2/ndf=SSE/(noise_V²*ndf)。
評価既定条件は波高≥8 mV・S/N≥5・非飽和等に加えchi2/ndf≤3、ノイズゼロは未定義として除外します。
相関ノイズ・テンプレート推定誤差はchi2へ含めていません。無信号chの時刻固定振幅推定は、このCFD50比較APIには含めません。

統計は両方成功した同一ショットの平均・標本標準偏差。位置×chごとに集計し、位置間の遅延差を分布幅へ混ぜません。
分布図の時間原点は線形法の平均を両手法共通で引きます。CSVはトリガー基準nsのままです。
ヒストグラムの範囲外件数を表示し、統計量は範囲外を含む全共通ショットで計算します。
テンプレートの5 ps格子や人工波形での精度を、実データの分解能改善と解釈しないでください。

参照元は `external/Hiroshima-TCT-wiki`（取得コミット9d5f009）の波形解析・解析READMEと提供メールです。
Wikiのテンプレート計算本体 `macro/template_timing` はこのクローンにはないため、ビン処理・pol2点数・
平滑化幅のsigma解釈・候補最低件数・上限はこの実装の明示仕様です。メールと完全な数値互換を保証するものではありません。

## Leading chのpropagation delay

`propagation_xy_maps` は既存の `AnalyzeScan` による平均波形・特徴量・XY格子を再利用します。
選択した全ショット（clippedを含む）をtrigger方式で平均し、ベースライン差し引き後の
`amplitude_mv` が最大のchを各位置で固定します。完全同値は小さいch番号を優先します。
既存 `RankChannels` の最小電圧順は変更しません。振幅差と平均に含まれたleading chのclipped件数も保存します。

選んだchの元波形ごとに `ExtractWaveformFeature` と同じ時間窓・ベースラインを使用します。
ノイズはベースラインの標本標準偏差（分母N−1）、S/Nは正の振幅をそのノイズで割った値です。
ノイズがゼロの正パルスはS/N条件を通し、S/N列を空欄にします。
clipped、信号窓端ピーク、非正振幅、振幅不足、S/N不足、交点なし、波形・窓不正は除外します。
複数の条件に該当する場合、CSVの理由はこの判定順で最初のものです。

負極性の信号を `s(t)=baseline−V(t)` とし、ベースライン窓終了以降から対象ピークまでの
`s[j] < fraction*A <= s[j+1]` を満たす最後の区間を使います。信号窓はピークを探す範囲で、
CFD交点自体は信号窓開始より前でも許可します。交点区間がなければ外挿しません。
交点が複数ある場合は最後の交点を採用し、`n_crossings` に件数を残します。
時刻は隣接サンプル間の線形補間で計算します。
`time_s` は各ショット・chの `t0_s + i*dt_s` なので、得られたCFD時刻がそのまま
レーザートリガー基準のpropagation delayです。`trigger_elapsed_s`、先頭サンプル時刻、
基準位置の到達時刻、chオフセットをさらに差し引きません。

位置の代表値は有効ショットの算術平均で、中央値も保存します。標準偏差は分母N−1、
平均の標準誤差は `stddev/sqrt(N)` です。これらは装置校正や長期ドリフトの系統誤差を含みません。
有効率の分母は要求ショット数で、最小有効件数を下回る位置を時間マップでマスクします。
ROOTの時間マップのマスク位置は0の仮値なので、`valid_mask_xy` を参照します。
標準偏差・標準誤差は有効件数2未満で未定義となり、有効件数マップも併せて参照します。
表示では標準偏差・標準誤差をpsに換算し、CSVの統計量はnsです。
